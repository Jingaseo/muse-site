移动端 H5 学术调查平台

一个基于 Supabase 的移动优先 H5 调查系统，供大学生完成关于黄金ETF信息接触与判断的实验任务。

核心功能

登录页、筛选页、情境展示、完整问卷、提交页，全程中文，保持参与者盲目信息。

实验设计实现

随机分配 3×2 组，隐藏 group_id、source_type、exposure_type 于后端，仅用于数据存储。

数据安全

使用 Supabase 行级安全，仅允许匿名 INSERT，所有个人可识别信息均不收集。

技术栈

HTML5、CSS3（mobile‑first）、JavaScript（Vue/React 可选），Supabase JS SDK 与 PostgreSQL。

确保盲目与数据完整

平台严格遵循实验盲盲要求并安全存储所有响应。
